**To-Do List**

## Overview
The **To-Do List** application is a simple, yet efficient tool to manage your daily tasks. It allows users to create, update, delete, and mark tasks as completed. With an easy-to-use interface, it helps users stay organized and focused by providing a clear overview of tasks that need to be done.

This project helps you track your goals and increase productivity by efficiently managing daily tasks.

## Features
- **Add Tasks**: Quickly add new tasks with descriptions.
- **Edit Tasks**: Modify task details after creation.
- **Delete Tasks**: Remove tasks that are no longer needed.
- **Mark Tasks as Complete**: Check off completed tasks for better task management.
- **Task Filtering**: Filter tasks based on status (completed or pending).
- **Local Storage**: The tasks are stored in local storage, so they persist even after the browser is closed.

## Installation
Follow these steps to set up the **To-Do List** project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/1Jyoshitha/to_do_list.git
   ```

2. Navigate to the project directory:
   ```bash
   cd to_do_list
   ```

3. Open the project in your browser by double-clicking the `index.html` file or using any local web server.

   **Note**: Since this project is a simple front-end application, you can run it directly in your browser without needing any server setup.

## Usage
1. **Add a Task**: Enter a task description and click "Add" to add it to the list.
2. **Mark as Completed**: Click the checkbox next to the task to mark it as completed.
3. **Edit Task**: If you need to make changes to a task, click the "Edit" button next to it.
4. **Delete Task**: Click the "Delete" button to remove a task from your list.
5. **Task Filtering**: Use the filter option to view completed, pending, or all tasks.
